# GICC 公開投稿画像

このフォルダは、GICCのInstagram／Facebook投稿に使用する**公開済み画像だけ**を保管します。画像はインターネット上で誰でも閲覧できます。

- 原稿・個人情報・GitHubトークン・契約資料・未公開の内部文書は置かない。
- 画像の公表内容・文字・キャラクター・著作権は人間が確認したうえで追加する。
- Instagram向けはJPEG画像（縦1080×1350、8MB以下）を推奨。
- Instagram自体への公開は別の操作。画像をこのリポジトリに置いてもSNSへ自動投稿されません。
- 公開前の確認と投稿の最終承認は必須。

※元原稿・制作ソースは非公開の別リポジトリで管理し、この公開フォルダには置きません。
